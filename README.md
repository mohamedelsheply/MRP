# نظام إدارة ومراقبة مخازن قطع الغيار

نظام ويب (يعمل بالكامل داخل المتصفح، بدون سيرفر أو قاعدة بيانات خارجية) لإدارة قطع الغيار، متابعة الرصيد، توليد طلبات الشراء تلقائيًا، ومراجعة حركات المخزون المستوردة من SAP (قائمة MB51).

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | هيكل الصفحة الرئيسي |
| `style.css` | التنسيقات والألوان (فاتح/ليلي) |
| `app.js` | كل منطق النظام (قراءة الملفات، المطابقة، التخزين، التقارير) |

## طريقة التشغيل

النظام لا يحتاج أي تثبيت أو خادم. يكفي فتح `index.html` مباشرة في المتصفح (Chrome أو Edge يفضّل)، أو نشر الملفات الثلاثة على أي استضافة ثابتة (GitHub Pages، Netlify، إلخ).

> يحتاج الجهاز اتصالاً بالإنترنت عند أول فتح لتحميل مكتبة Bootstrap وخط Tajawal ومكتبة قراءة ملفات إكسل (SheetJS) من الـ CDN.

## المزايا الرئيسية

- **بيانات أساسية للأصناف** (كود، وصف، موقع تخزين، شركة، حدود أدنى/أقصى) محفوظة تلقائيًا على جهاز المستخدم (IndexedDB).
- **تحديث دوري للرصيد** عبر رفع شيت إكسل، مع مطابقة صارمة على (الكود + الشركة + موقع التخزين).
- **توليد تلقائي لتقرير طلب الشراء** المقترح بناءً على الحدود الدنيا والقصوى.
- **أرشيف** لكل الطلبات المحفوظة سابقًا.
- **نسخ احتياطي/استرجاع كامل** لكل بيانات النظام كملف JSON واحد.
- **مراجعة حركات المخزن (MB51)**: كشف حركات صرف عهدة/تكهين بدون مرفق، عهد بدون مرتجع، مرتجعات تالفة بدون تكهين، ومرتجعات تحتاج صيانة بدون دخول دورة صيانة. البيانات المرفوعة تتراكم تلقائيًا على جهاز المستخدم بمرور الوقت.
- **وضع ليلي (Dark Mode)** يُحفظ تلقائيًا حسب اختيار المستخدم.

## ملاحظة هامة على الخصوصية

كل البيانات (الأصناف، الطلبات، حركات المراجعة) تُخزَّن محليًا داخل متصفح المستخدم فقط (IndexedDB)، ولا تُرسل لأي خادم خارجي. مسح بيانات التصفح (Clear browsing data) يمسح هذه البيانات أيضًا، لذا يُنصح بأخذ نسخة احتياطية دورية من داخل النظام.
